## 快速体验

```bash
# 创建一个新的 Tona 主题项目
pnpm create tona

# 进入项目并安装依赖
cd my-tona-theme
pnpm install

# 本地开发（支持热更新）
pnpm dev

# 构建分发产物
pnpm build
```

## 一个最小的主题

```ts
import { createTheme } from 'tona'
import { background, darkMode, codeHighlight } from 'tona-plugins'

const theme = createTheme()

theme.use(background)
theme.use(darkMode)
theme.use(codeHighlight)
```
